# 前端故障排查指南

## 问题：http://localhost:3000/ 打不开

### 步骤1: 检查前端服务是否启动

```bash
# 进入前端目录
cd web/frontend

# 检查是否有node_modules目录
ls node_modules

# 如果没有，先安装依赖
npm install

# 启动服务
npm run dev
```

### 步骤2: 检查端口是否被占用

```bash
# Windows PowerShell
netstat -ano | findstr :3000

# 如果端口被占用，可以：
# 1. 关闭占用端口的程序
# 2. 或者修改端口（见步骤3）
```

### 步骤3: 修改端口（如果3000被占用）

编辑 `vite.config.js`：

```javascript
server: {
  port: 3001,  // 改为其他端口
  // ...
}
```

然后访问：http://localhost:3001

### 步骤4: 检查Node.js版本

```bash
node --version
```

需要 Node.js >= 16

### 步骤5: 清除缓存重新安装

```bash
cd web/frontend

# 删除node_modules和锁文件
rm -rf node_modules package-lock.json

# Windows PowerShell
Remove-Item -Recurse -Force node_modules, package-lock.json

# 清除npm缓存
npm cache clean --force

# 重新安装
npm install

# 启动
npm run dev
```

### 步骤6: 检查浏览器控制台错误

1. 打开浏览器开发者工具（F12）
2. 查看Console标签页的错误信息
3. 查看Network标签页，确认资源是否加载成功

### 步骤7: 检查代码语法错误

如果控制台有错误，可能是代码问题。常见错误：

1. **导入错误**：检查所有import语句
2. **组件未注册**：确保所有组件都已正确导入
3. **语法错误**：检查是否有拼写错误

### 步骤8: 使用备用启动方式

如果 `npm run dev` 不工作，尝试：

```bash
# 使用npx直接运行
npx vite

# 或者指定完整路径
npx vite --config vite.config.js
```

## 快速诊断命令

```bash
# 1. 检查Node.js和npm
node --version
npm --version

# 2. 检查依赖是否安装
cd web/frontend
ls node_modules | head -5

# 3. 检查package.json
cat package.json

# 4. 尝试启动（查看详细错误）
npm run dev -- --debug
```

## 常见错误及解决方案

### 错误1: Cannot find module 'xxx'

**解决**：运行 `npm install`

### 错误2: Port 3000 is already in use

**解决**：修改端口或关闭占用端口的程序

### 错误3: Failed to resolve import

**解决**：检查导入路径是否正确，确保文件存在

### 错误4: Element Plus相关错误

**解决**：确保已安装 `element-plus` 和 `@element-plus/icons-vue`

```bash
npm install element-plus @element-plus/icons-vue
```

## 如果还是无法解决

1. 查看终端输出的完整错误信息
2. 查看浏览器控制台的错误信息
3. 检查是否有防火墙阻止
4. 尝试使用其他端口
