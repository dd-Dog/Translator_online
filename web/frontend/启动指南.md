# 前端启动指南

## 快速启动

### 1. 进入前端目录

```bash
cd web/frontend
```

### 2. 安装依赖（首次运行）

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm run dev
```

### 4. 访问

打开浏览器访问：http://localhost:3000

## 常见问题

### Q1: 端口3000被占用

**解决方案**：
```bash
# 方式1: 修改vite.config.js中的端口
# 将 port: 3000 改为其他端口，如 port: 3001

# 方式2: 使用命令行指定端口
npm run dev -- --port 3001
```

### Q2: npm install 失败

**解决方案**：
```bash
# 清除缓存
npm cache clean --force

# 删除node_modules和package-lock.json
rm -rf node_modules package-lock.json

# 重新安装
npm install
```

### Q3: 编译错误

**检查**：
1. 确保Node.js版本 >= 16
2. 检查控制台错误信息
3. 查看是否有语法错误

### Q4: 页面空白

**检查**：
1. 打开浏览器开发者工具（F12）
2. 查看Console标签页的错误信息
3. 查看Network标签页，确认资源加载是否成功

### Q5: 无法连接后端API

**检查**：
1. 确保后端服务已启动（http://localhost:8000）
2. 检查 `vite.config.js` 中的proxy配置
3. 检查后端CORS配置

## 开发模式

开发服务器支持热重载，修改代码后会自动刷新页面。

## 构建生产版本

```bash
npm run build
```

构建产物在 `dist/` 目录。
