# 前端快速启动

## 方法1: 使用启动脚本（推荐）

### Windows
双击 `start.bat` 文件

### Linux/Mac
```bash
chmod +x start.sh
./start.sh
```

## 方法2: 手动启动

### 1. 进入前端目录
```bash
cd web/frontend
```

### 2. 安装依赖（首次运行）
```bash
npm install
```

### 3. 启动服务
```bash
npm run dev
```

### 4. 访问
打开浏览器访问：http://localhost:3000

## 如果端口3000被占用

修改 `vite.config.js` 中的端口号：
```javascript
server: {
  port: 3001,  // 改为其他端口
  // ...
}
```

然后访问：http://localhost:3001

## 检查服务是否启动成功

启动成功后，终端会显示：
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
```

如果看到这个信息，说明服务已启动。

## 常见问题

### 问题1: 页面空白或404

**解决**：确保访问的是 http://localhost:3000/ （注意末尾的斜杠）

### 问题2: 无法连接后端

**解决**：
1. 确保后端服务已启动（http://localhost:8000）
2. 检查后端服务是否正常运行

### 问题3: 编译错误

**解决**：
1. 查看终端输出的错误信息
2. 检查是否有语法错误
3. 尝试清除缓存：`npm cache clean --force` 然后重新 `npm install`
