# Web服务启动说明

## 快速启动

### 1. 后端服务

```bash
# 进入后端目录
cd web/backend

# 安装依赖
pip install -r requirements.txt

# 配置环境变量（复制.env.example为.env并填写）
cp .env.example .env
# 编辑.env文件，填入API密钥

# 启动服务
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

后端服务启动后，访问 http://localhost:8000/docs 查看API文档。

### 2. 前端服务

```bash
# 进入前端目录
cd web/frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端服务启动后，访问 http://localhost:3000

## 配置说明

### 后端配置

1. **API密钥配置** (`.env`文件)
   ```env
   OPENROUTER_API_KEY=sk-or-v1-your-key-here
   QWEN_API_KEY=your-qwen-key-here
   DEEPSEEK_API_KEY=your-deepseek-key-here
   ```

2. **安全配置** (`app/config.py`)
   - IP白名单：修改 `ALLOWED_IPS`
   - Token认证：在 `.env` 中设置 `SHARED_TOKEN`

### 前端配置

1. **API地址** (`.env.local`文件，可选)
   ```env
   VITE_API_BASE_URL=http://localhost:8000
   VITE_SHARED_TOKEN=your-group-secret-token-12345
   ```

## 常见问题

### Q: 后端启动失败，提示"无法创建翻译Pipeline"

**A**: 检查：
1. `config/models.yaml` 中的模型配置是否正确
2. `.env` 文件中的API密钥是否正确
3. 工作流配置的模型是否已启用

### Q: 前端无法连接后端

**A**: 检查：
1. 后端服务是否已启动（http://localhost:8000）
2. 前端 `.env.local` 中的 `VITE_API_BASE_URL` 是否正确
3. 如果后端启用了IP白名单，确保前端访问的IP在允许列表中
4. 如果后端启用了Token认证，确保前端配置了 `VITE_SHARED_TOKEN`

### Q: WebSocket连接失败

**A**: 检查：
1. 后端服务是否正常运行
2. 防火墙是否阻止了WebSocket连接
3. 浏览器控制台是否有错误信息

## 开发建议

1. **开发环境**: 使用 `ENV=development`，禁用IP白名单和Token认证
2. **生产环境**: 使用 `ENV=production`，启用IP白名单或Token认证
3. **API文档**: 访问 http://localhost:8000/docs 查看完整的API文档
