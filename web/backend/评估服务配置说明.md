# 评估服务配置说明

## 概述

评估功能需要调用外部的评估服务API。当前实现支持两种模式：

1. **真实评估服务**：配置评估服务URL，调用真实的评估API
2. **模拟数据**：如果评估服务不可用，返回模拟数据（用于开发测试）

## 配置方法

### 方法1: 环境变量（推荐）

在 `.env` 文件中添加：

```env
EVALUATION_SERVICE_URL=http://localhost:8001
```

### 方法2: 系统环境变量

```bash
# Windows PowerShell
$env:EVALUATION_SERVICE_URL="http://localhost:8001"

# Linux/Mac
export EVALUATION_SERVICE_URL="http://localhost:8001"
```

## 评估服务API规范

评估服务需要提供以下API端点：

**POST /api/evaluate**

请求体：
```json
{
  "source": "源文本",
  "translation": "翻译文本",
  "reference": "参考译文（可选）"
}
```

响应：
```json
{
  "scores": {
    "BLEU": 0.85,
    "BERTScore": 0.92,
    "COMET": 0.88,
    "BLEURT": 0.90,
    "ChrF": 0.87
  },
  "overall": 0.88
}
```

## 注意事项

1. 如果未配置 `EVALUATION_SERVICE_URL` 或评估服务不可用，系统会返回模拟数据
2. 模拟数据仅用于开发测试，不能用于生产环境
3. 评估服务应该有30秒的超时时间
4. 评估服务应该返回标准的JSON格式

## 测试

启动后端服务后，可以通过以下方式测试：

```bash
curl -X POST http://localhost:8000/api/v1/evaluation/evaluate \
  -H "Content-Type: application/json" \
  -d '{
    "source": "Hello world",
    "translation": "你好世界"
  }'
```
