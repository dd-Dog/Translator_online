# 免费模型配置指南

## 📋 概述

为了减少测试费用，系统已配置为使用国内免费模型（DeepSeek 和 Qwen）。本指南说明如何配置和使用不同的模型组合。

## 🎯 支持的模型

### DeepSeek 模型

- **deepseek-chat**: 免费模型，适合日常使用
- **deepseek-reasoner**: 推理模型（如果API支持）

### Qwen 模型

- **qwen-turbo**: 免费额度模型，速度快
- **qwen-plus**: 付费模型，质量更高
- **qwen-max**: 付费模型，质量最高

## ⚙️ 配置方式

### 方式1: 使用配置文件（推荐）

编辑 `config/models.yaml` 文件：

```yaml
# 工作流Agent配置
workflow:
  planner:
    model: "deepseek"  # 或 "qwen", "qwen_plus"
  translator_a:
    model: "deepseek"  # 或 "qwen", "qwen_plus"
  translator_b:
    model: "qwen"  # 或 "deepseek", "qwen_plus"
  checker:
    model: "deepseek"  # 或 "qwen", "qwen_plus"
  stylist:
    model: "qwen"  # 或 "deepseek", "qwen_plus"
  aggregator:
    model: "deepseek"  # 或 "qwen", "qwen_plus"
```

### 方式2: 在代码中动态配置

在 `evaluate_flores_batch.py` 中：

```python
# 自定义模型配置
model_config = {
    "planner": "deepseek",
    "translator_a": "deepseek",
    "translator_b": "qwen",
    "checker": "deepseek",
    "stylist": "qwen",
    "aggregator": "deepseek"
}
pipeline = create_pipeline(model_config)
```

## 📊 推荐配置方案

### 方案1: 全部使用DeepSeek（最省钱）

**适用场景**: 预算有限，追求最低成本

```yaml
workflow:
  planner: "deepseek"
  translator_a: "deepseek"
  translator_b: "deepseek"
  checker: "deepseek"
  stylist: "deepseek"
  aggregator: "deepseek"
```

**优点**:
- ✅ 完全免费
- ✅ 成本最低
- ✅ 配置简单

**缺点**:
- ⚠️ 所有阶段使用同一模型，多样性较低

### 方案2: DeepSeek + Qwen混合（推荐）

**适用场景**: 平衡质量和成本

```yaml
workflow:
  planner: "deepseek"
  translator_a: "deepseek"
  translator_b: "qwen"
  checker: "deepseek"
  stylist: "qwen"
  aggregator: "deepseek"
```

**优点**:
- ✅ 使用免费模型
- ✅ 不同模型提供多样性
- ✅ 质量与成本平衡

**缺点**:
- ⚠️ 需要配置两个API密钥

### 方案3: 使用Qwen Plus（更高质量）

**适用场景**: 追求更高质量，有付费预算

```yaml
workflow:
  planner: "qwen_plus"
  translator_a: "qwen_plus"
  translator_b: "qwen_plus"
  checker: "qwen_plus"
  stylist: "qwen_plus"
  aggregator: "qwen_plus"
```

**优点**:
- ✅ 质量更高
- ✅ 统一模型，配置简单

**缺点**:
- ⚠️ 需要付费
- ⚠️ 成本较高

### 方案4: 混合使用不同模型（实验性）

**适用场景**: 测试不同模型组合的效果

```yaml
workflow:
  planner: "deepseek"        # 规划任务
  translator_a: "qwen_plus"   # 主翻译（高质量）
  translator_b: "qwen"       # 对照翻译（免费）
  checker: "deepseek"        # 检查（免费）
  stylist: "qwen"            # 风格化（免费）
  aggregator: "deepseek"     # 整合（免费）
```

## 🔧 配置步骤

### 1. 获取API密钥

**DeepSeek**:
1. 访问 https://platform.deepseek.com/
2. 注册/登录账号
3. 获取API密钥
4. 添加到 `.env` 文件: `DEEPSEEK_API_KEY=your_key_here`

**Qwen**:
1. 访问 https://dashscope.console.aliyun.com/
2. 注册/登录账号
3. 获取API密钥
4. 添加到 `.env` 文件: `QWEN_API_KEY=your_key_here`

### 2. 配置模型

编辑 `config/models.yaml`，确保以下模型已启用：

```yaml
models:
  deepseek:
    enabled: true
    model: "deepseek-chat"
    api_key_env: "DEEPSEEK_API_KEY"
    base_url: "https://api.deepseek.com"
  
  qwen:
    enabled: true
    model: "qwen-turbo"
    api_key_env: "QWEN_API_KEY"
    base_url: "https://dashscope.aliyuncs.com/compatible-mode/v1"
```

### 3. 配置工作流

编辑 `config/models.yaml` 的 `workflow` 部分，选择上述方案之一。

### 4. 测试配置

运行快速测试：

```bash
python test_evaluation_quick.py
```

## 📝 使用不同模型的方法

### 方法1: 修改配置文件

直接编辑 `config/models.yaml`，修改 `workflow` 部分的模型名称。

### 方法2: 在脚本中动态配置

在 `evaluate_flores_batch.py` 的 `main()` 函数中：

```python
# 方案A: 全部DeepSeek
model_config = {
    "planner": "deepseek",
    "translator_a": "deepseek",
    "translator_b": "deepseek",
    "checker": "deepseek",
    "stylist": "deepseek",
    "aggregator": "deepseek"
}

# 方案B: DeepSeek + Qwen混合
model_config = {
    "planner": "deepseek",
    "translator_a": "deepseek",
    "translator_b": "qwen",
    "checker": "deepseek",
    "stylist": "qwen",
    "aggregator": "deepseek"
}

# 方案C: 使用Qwen Plus
model_config = {
    "planner": "qwen_plus",
    "translator_a": "qwen_plus",
    "translator_b": "qwen_plus",
    "checker": "qwen_plus",
    "stylist": "qwen_plus",
    "aggregator": "qwen_plus"
}

pipeline = create_pipeline(model_config)
```

### 方法3: 使用不同的Qwen模型

在 `config/models.yaml` 中配置多个Qwen模型：

```yaml
models:
  qwen:
    enabled: true
    model: "qwen-turbo"  # 免费模型
    api_key_env: "QWEN_API_KEY"
  
  qwen_plus:
    enabled: true
    model: "qwen-plus"  # 付费模型
    api_key_env: "QWEN_API_KEY"
  
  qwen_max:
    enabled: true
    model: "qwen-max"  # 最高质量
    api_key_env: "QWEN_API_KEY"
```

然后在 `workflow` 中选择：

```yaml
workflow:
  translator_a: "qwen_plus"  # 使用qwen-plus
  translator_b: "qwen"        # 使用qwen-turbo
```

## 💡 最佳实践

1. **测试阶段**: 使用方案1（全部DeepSeek）或方案2（DeepSeek+Qwen混合）
2. **生产环境**: 根据质量要求选择方案2或方案3
3. **实验对比**: 使用方案4测试不同模型组合的效果
4. **成本控制**: 优先使用免费模型，关键步骤（如aggregator）可使用付费模型

## ⚠️ 注意事项

1. **API密钥**: 确保 `.env` 文件中包含所有必需的API密钥
2. **模型启用**: 确保要使用的模型在 `models` 部分已启用（`enabled: true`）
3. **模型名称**: 确保 `workflow` 中使用的模型名称与 `models` 中的键名一致
4. **免费额度**: Qwen有免费额度限制，注意监控使用量
5. **DeepSeek**: DeepSeek目前免费，但可能有使用限制

## 🐛 故障排除

### 问题1: 模型创建失败

**错误**: `部分模型创建失败，请检查配置`

**解决**:
1. 检查API密钥是否正确配置
2. 检查模型是否已启用（`enabled: true`）
3. 检查模型名称是否正确

### 问题2: API调用失败

**错误**: API返回错误

**解决**:
1. 检查API密钥是否有效
2. 检查账户余额（Qwen付费模型）
3. 检查网络连接
4. 查看API文档确认模型名称

### 问题3: 模型未找到

**错误**: `模型 xxx 未启用`

**解决**:
1. 在 `config/models.yaml` 中启用该模型
2. 检查模型名称拼写是否正确
