# 评估器环境使用说明

## 问题说明

如果你在 `translator_eval` conda 环境中安装了 COMET 和 BLEURT，但运行测试脚本时仍然提示"未安装"，这是因为：

**脚本使用的是当前 Python 环境的解释器，而不是 `translator_eval` 环境的解释器。**

## 解决方案

### 方法1: 使用启动脚本（推荐）

**Windows:**
```bash
run_test_evaluator_env.bat
```

**Linux/Mac:**
```bash
chmod +x run_test_evaluator_env.sh
./run_test_evaluator_env.sh
```

启动脚本会自动使用 `translator_eval` 环境的 Python 运行测试。

### 方法2: 手动激活环境

```bash
# 激活环境
conda activate translator_eval

# 运行测试
python test_evaluator_env.py
```

### 方法3: 直接使用环境 Python

**Windows:**
```bash
C:\Users\ddDog\miniconda3\envs\translator_eval\python.exe test_evaluator_env.py
```

**Linux/Mac:**
```bash
~/miniconda3/envs/translator_eval/bin/python test_evaluator_env.py
```

## 验证环境

运行以下命令验证 COMET 和 BLEURT 是否在 `translator_eval` 环境中：

```bash
# Windows
C:\Users\ddDog\miniconda3\envs\translator_eval\python.exe -c "import comet; print('COMET已安装')"
C:\Users\ddDog\miniconda3\envs\translator_eval\python.exe -c "import bleurt; print('BLEURT已安装')"

# Linux/Mac
~/miniconda3/envs/translator_eval/bin/python -c "import comet; print('COMET已安装')"
~/miniconda3/envs/translator_eval/bin/python -c "import bleurt; print('BLEURT已安装')"
```

## 配置说明

在 `config/evaluation.yaml` 中配置了 `translator_eval` 环境：

```yaml
evaluator_env:
  conda_env_name: "translator_eval"
  use_current_env: false
```

这个配置告诉系统：
- 使用 `translator_eval` conda 环境
- 不使用当前环境的 Python

## 常见问题

### Q: 为什么脚本检测到环境不匹配？

A: 脚本会检查当前 Python 是否是指定环境的 Python。如果不匹配，会显示警告。这是正常的，只需要使用正确的方法运行脚本即可。

### Q: 能否在当前环境安装 COMET 和 BLEURT？

A: 可以，但建议使用单独的 conda 环境，因为：
- COMET 和 BLEURT 依赖较多，可能与其他包冲突
- 环境隔离更清晰，便于管理

### Q: 网络问题导致模型下载失败怎么办？

A: COMET 和 BLEURT 需要从 HuggingFace 下载模型。如果网络不稳定：
- 可以配置代理
- 或者使用离线模式（需要预先下载模型）
