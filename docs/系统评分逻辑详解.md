## 为什么所有评分都是0.85？

### 完整的评分流程

```
1. Checker调用GPT-4评分
   ↓
2. GPT-4返回响应（可能包含JSON格式的评分）
   ↓
3. 解析响应提取评分
   ↓
   ├─ 解析成功 → 使用模型返回的分数（或默认0.8）
   └─ 解析失败 → 使用默认分数 0.8, 0.8, 0.8, 0.8  ← 👈 问题根源
   ↓
4. Aggregator固定提升+0.05
   ↓
5. 最终评分 = 0.8 + 0.05 = 0.85  ← 👈 这就是为什么都是0.85
```

### 根本原因

**GPT-4没有返回有效的JSON评分** ❌

让我们看看实际的GPT-4响应是什么：

```python
# Checker期望的JSON格式
{
    "quality_scores": {
        "translator_a": {
            "adequacy": 0.9,
            "fluency": 0.85,
            "terminology": 0.9,
            "overall": 0.88
        }
    }
}

# 但GPT-4可能实际返回的是自然语言，而非严格的JSON
```

**解析流程**:

```python
# src/agents/checker.py: 第128-178行
json_match = re.search(r'\{.*\}', response_text, re.DOTALL)  # 尝试提取JSON
if json_match:
    try:
        data = json.loads(json_match.group())  # 尝试解析JSON
        # ... 提取评分 ...
    except Exception as e:
        pass  # 👈 解析失败，静默跳过
        
# 如果解析失败，返回默认0.8
return CheckerReport(..., quality_scores={segment_id: QualityScore(0.8, 0.8, 0.8, 0.8)})
```

**结论**: 
1. GPT-4没有严格返回JSON格式
2. 或者返回了JSON但格式不符合预期
3. 解析失败后使用默认值0.8
4. Aggregator固定提升+0.05
5. **最终所有评分都是0.85**

## 问题定位

### 问题1: JSON解析失败

**原因**: 
- GPT-4可能返回混合格式（文本+JSON）
- JSON格式不严格
- 正则表达式提取不准确

**示例**（可能的GPT-4响应）:
```
经过评估，两个翻译版本质量都很好。

评分结果：
{
    "consistent": true,
    "quality_scores": {
        "translator_a": {
            "adequacy": 0.9,
            ...
        }
    }
}
```

**解决方案**:
```python
# 改进JSON提取
json_match = re.search(r'\{[^{}]*(?:\{[^{}]*\}[^{}]*)*\}', response_text, re.DOTALL)

# 或者强制模型返回纯JSON
prompt += "\n\n请**只**返回JSON格式，不要有其他文字说明。"
```

### 问题2: 循环覆盖

```python
# src/agents/checker.py: 第161-168行
for translator, scores in scores_data.items():  # 👈 循环
    quality_scores[segment_id] = QualityScore(...)  # 👈 每次都覆盖同一个key
```

**问题**: 
- `translator_a` 和 `translator_b` 的评分会互相覆盖
- 最后只保留一个评分
- 应该分别保存或取平均

**当前逻辑**:
```
第1次循环: quality_scores[segment_id] = translator_a的评分
第2次循环: quality_scores[segment_id] = translator_b的评分  ← 覆盖了translator_a
```

**结果**: 只保留了translator_b的评分（或最后一个translator的评分）

## 解决方案

### 方案1: 修复JSON解析（立即实施）

```python
def _parse_check_response(self, response_text: str, segment_id: str) -> CheckerReport:
    import json
    import re
    
    # 改进1: 添加调试日志
    from loguru import logger
    logger.debug(f"Checker响应: {response_text[:200]}...")
    
    # 改进2: 多种JSON提取策略
    # 策略1: 提取完整JSON对象（支持嵌套）
    json_match = re.search(r'\{(?:[^{}]|(?:\{(?:[^{}]|(?:\{[^{}]*\}))*\}))*\}', response_text, re.DOTALL)
    
    # 策略2: 如果策略1失败，尝试提取代码块中的JSON
    if not json_match:
        json_match = re.search(r'```json\s*(\{.*?\})\s*```', response_text, re.DOTALL)
    
    # 策略3: 提取最后一个完整的{}块
    if not json_match:
        all_matches = re.finditer(r'\{[^{}]*(?:\{[^{}]*\}[^{}]*)*\}', response_text, re.DOTALL)
        matches_list = list(all_matches)
        if matches_list:
            json_match = matches_list[-1]
    
    if json_match:
        try:
            json_text = json_match.group(1) if json_match.lastindex else json_match.group()
            data = json.loads(json_text)
            logger.debug(f"JSON解析成功: {list(data.keys())}")
            
            # 改进3: 正确处理多个translator的评分
            quality_scores = {}
            scores_data = data.get('quality_scores', {})
            
            # 收集所有translator的评分
            all_scores = []
            for translator, scores in scores_data.items():
                all_scores.append({
                    'adequacy': scores.get('adequacy', 0.8),
                    'fluency': scores.get('fluency', 0.8),
                    'terminology': scores.get('terminology', 0.8),
                    'overall': scores.get('overall', 0.8)
                })
            
            # 取平均分（而非覆盖）
            if all_scores:
                avg_adequacy = sum(s['adequacy'] for s in all_scores) / len(all_scores)
                avg_fluency = sum(s['fluency'] for s in all_scores) / len(all_scores)
                avg_terminology = sum(s['terminology'] for s in all_scores) / len(all_scores)
                avg_overall = sum(s['overall'] for s in all_scores) / len(all_scores)
                
                quality_scores[segment_id] = QualityScore(
                    adequacy=avg_adequacy,
                    fluency=avg_fluency,
                    terminology=avg_terminology,
                    overall=avg_overall
                )
            
            return CheckerReport(...)
            
        except Exception as e:
            logger.warning(f"JSON解析失败: {e}")
            # 使用默认值
    
    # 解析失败，返回默认0.8
    logger.warning("未找到有效JSON，使用默认评分0.8")
    return CheckerReport(..., quality_scores={segment_id: QualityScore(0.8, 0.8, 0.8, 0.8)})
```
