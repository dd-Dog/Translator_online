# 机器翻译评估数据集推荐

## 标准评估数据集

### 1. WMT（Workshop on Machine Translation）⭐⭐⭐⭐⭐

**推荐指数**: ⭐⭐⭐⭐⭐

**简介**: 
- 机器翻译领域最权威的评测比赛
- 每年更新，包含多个语言对
- 包含人工评分的参考翻译

**数据集**:
- WMT23, WMT22, WMT21等
- 包含新闻、生物医学、通用领域等
- 语言对：英中、中英、英德、英法等

**获取方式**:
```bash
# 通过HuggingFace下载
pip install datasets
```

```python
from datasets import load_dataset

# WMT19 中英翻译
dataset = load_dataset("wmt19", "zh-en")

# WMT22
dataset = load_dataset("wmt22", "zh-en")
```

**数据格式**:
```python
{
    "translation": {
        "en": "Machine learning is...",
        "zh": "机器学习是..."
    }
}
```

**优势**:
- ✅ 权威性高
- ✅ 有人工评分
- ✅ 多领域覆盖
- ✅ 持续更新

**适用场景**: 
- 学术研究
- 论文实验
- 模型对比

**数据量**: 
- 测试集：1000-3000条
- 验证集：1000-2000条

## 评估指标推荐

### 自动评估指标

1. **BLEU** (Bilingual Evaluation Understudy)
   - 最常用的机器翻译评估指标
   - 基于n-gram匹配

```python
from nltk.translate.bleu_score import sentence_bleu

reference = "机器学习是人工智能的一个子集"
candidate = "机器学习是人工智能的子领域"

score = sentence_bleu([reference.split()], candidate.split())
```

2. **COMET** (Crosslingual Optimized Metric for Evaluation of Translation)
   - 基于神经网络的评估
   - 相关性更高

```python
from comet import download_model, load_from_checkpoint

model_path = download_model("Unbabel/wmt22-comet-da")
model = load_from_checkpoint(model_path)

data = [{
    "src": source_text,
    "mt": translation,
    "ref": reference
}]

scores = model.predict(data)
```

3. **BERTScore**
   - 基于BERT的语义相似度
   - 考虑语义而非表面形式

```python
from bert_score import score

P, R, F1 = score([candidate], [reference], lang="zh")
```

## 评估指标建议

### 人工评估（必要）

7. **人工打分**: 抽样50-100条
8. **相关性分析**: 你的评分与人工评分的相关性
