# 翻译质量评分流程详解

## 当前评分流程概述

我们的评分系统基于**MQM（Multidimensional Quality Metrics）简化版**，通过多阶段、多模型协作来保证评分的客观性。

## 评分流程架构

```
原文 + 两个翻译版本
        ↓
    Checker Agent (GPT-4)
        ↓
    生成质量评分
        ↓
    Aggregator 整合
        ↓
    最终质量评分
```

## 详细评分流程

### 阶段1: 双重翻译（提供评分基础）

**Translator-A (Gemini)**
- 擅长多语言通用翻译
- 输出：翻译文本 + 自检报告（标记不确定的部分）

**Translator-B (Qwen)**
- 擅长中文自然表达
- 输出：翻译文本 + 自检报告

**目的**: 通过两个不同模型的翻译，提供对比基础

### 阶段2: 质量评估（核心评分阶段）

**Checker Agent (GPT-4 via OpenRouter)**

#### 评分标准（MQM简化版）

1. **充分性 (Adequacy)**: 0-1分
   - 评估标准：翻译是否完整传达了原文的所有信息
   - 检查项：
     - 是否有遗漏的内容
     - 是否有添加的内容
     - 核心意思是否准确

2. **流畅性 (Fluency)**: 0-1分
   - 评估标准：翻译是否自然流畅，符合目标语言习惯
   - 检查项：
     - 语法是否正确
     - 表达是否自然
     - 是否符合目标语言习惯

3. **术语准确性 (Terminology)**: 0-1分
   - 评估标准：专业术语翻译是否准确
   - 检查项：
     - 专业术语是否正确
     - 术语使用是否一致
     - 是否符合领域规范

4. **总体评分 (Overall)**: 0-1分
   - 计算方式：三项指标的平均值或加权平均

#### Checker的评分方法

```python
# Checker提示词要求模型返回JSON格式的评分
{
    "quality_scores": {
        "translator_a": {
            "adequacy": 0.9,      # 充分性
            "fluency": 0.85,      # 流畅性
            "terminology": 0.9,   # 术语准确性
            "overall": 0.88       # 总体
        },
        "translator_b": {
            "adequacy": 0.88,
            "fluency": 0.9,
            "terminology": 0.85,
            "overall": 0.88
        }
    }
}
```

**关键特点**：
- 使用GPT-4进行评分（专业能力强）
- 同时评估两个翻译版本
- 提供具体的评分依据（冲突、遗漏、误解）
- 低温度参数（0.2）保证评分稳定性

### 阶段3: 风格化后的质量提升

**Aggregator Agent (GPT-4)**

在最终整合阶段，会对经过风格化的翻译进行质量提升评估：

```python
# 假设经过风格化后质量有所提升
final_quality = QualityScore(
    adequacy=min(1.0, original_score.adequacy + 0.05),
    fluency=min(1.0, original_score.fluency + 0.05),
    terminology=min(1.0, original_score.terminology + 0.05),
    overall=min(1.0, original_score.overall + 0.05)
)
```

**提升逻辑**：
- 风格化阶段统一了术语 → 术语准确性提升
- 风格化阶段优化了表达 → 流畅性提升
- 默认提升0.05分（保守估计）

## 当前评分流程的问题

### ⚠️ 客观性问题

1. **主观性较强**
   - 依赖单个模型（GPT-4）的判断
   - 没有参考标准答案
   - 评分标准可能不一致

2. **固定提升值**
   - Aggregator阶段固定提升0.05分
   - 没有实际评估风格化的效果
   - 可能不够准确

3. **缺少对比基准**
   - 没有人工评分对照
   - 没有标准测试集
   - 难以验证评分准确性

4. **评分粒度**
   - 只有三个维度（充分性、流畅性、术语）
   - MQM标准有更多维度（如语法错误、拼写错误等）

#### 2. 基于规则的客观指标

```python
# 添加客观指标
class ObjectiveMetrics:
    def calculate_length_ratio(self, source, target):
        """长度比例（异常值检测）"""
        ratio = len(target) / len(source)
        # 正常范围：0.5-2.0
        if ratio < 0.5 or ratio > 2.0:
            return 0.5  # 降低评分
        return 1.0
    
    def calculate_terminology_consistency(self, text, glossary):
        """术语一致性检查"""
        # 检查术语表中的词是否正确翻译
        score = 0.0
        for term, translation in glossary.items():
            if term in source and translation in target:
                score += 1.0
        return score / len(glossary) if glossary else 1.0
    
    def detect_untranslated_content(self, target):
        """检测未翻译内容"""
        # 检查是否有英文残留（如果目标是中文）
        import re
        english_words = re.findall(r'[a-zA-Z]{3,}', target)
        if len(english_words) > 2:
            return 0.8  # 降低评分
        return 1.0
```

#### 5. 人工评分校准

```python
# 收集人工评分，校准模型评分
def calibrate_scores(model_scores, human_scores):
    """
    使用人工评分校准模型评分
    model_scores: 模型给出的评分
    human_scores: 人工评分
    """
    # 计算偏差
    bias = mean(human_scores) - mean(model_scores)
    
    # 调整模型评分
    calibrated_scores = model_scores + bias
    return calibrated_scores
```

```python
class DetailedMQM:
    """完整的MQM评分系统"""
    
    error_types = {
        "accuracy": {
            "mistranslation": -5,      # 误译
            "omission": -3,            # 遗漏
            "addition": -1,            # 添加
            "untranslated": -5         # 未翻译
        },
        "fluency": {
            "grammar": -3,             # 语法错误
            "spelling": -1,            # 拼写错误
            "punctuation": -0.5,       # 标点错误
            "inconsistency": -2        # 不一致
        },
        "style": {
            "awkward": -2,             # 表达生硬
            "unnatural": -3,           # 不自然
            "register": -1             # 语域不当
        },
        "terminology": {
            "inappropriate": -5,       # 术语不当
            "inconsistent": -3         # 术语不一致
        }
    }
    
    def calculate_mqm_score(self, errors):
        """根据错误计算MQM分数"""
        total_penalty = sum(error['weight'] for error in errors)
        # MQM分数 = 100 - 总扣分
        return max(0, 100 - total_penalty) / 100
```

```python
class NeuralQualityEstimator:
```

## 推荐的改进方案

### 方案1: 多模型评分投票（推荐，立即可实施）

**实现步骤**：

1. 使用3个不同模型进行评分
2. 取平均值作为最终评分
3. 计算标准差，评估评分一致性

**代码示例**：

```python
class MultiModelChecker:
    """多模型评分"""
    
    def __init__(self, models: List[BaseModel]):
        self.checkers = [Checker(model) for model in models]
    
    async def check(self, source, draft_a, draft_b, segment_id):
        """多模型评分"""
        reports = []
        
        # 并发调用多个checker
        tasks = [
            checker.check(source, draft_a, draft_b, segment_id)
            for checker in self.checkers
        ]
        reports = await asyncio.gather(*tasks)
        
        # 合并评分（取平均）
        all_scores = []
        for report in reports:
            if segment_id in report.quality_scores:
                all_scores.append(report.quality_scores[segment_id])
        
        if all_scores:
            avg_score = QualityScore(
                adequacy=mean([s.adequacy for s in all_scores]),
                fluency=mean([s.fluency for s in all_scores]),
                terminology=mean([s.terminology for s in all_scores]),
                overall=mean([s.overall for s in all_scores])
            )
            
            # 计算标准差（评估一致性）
            std_dev = std([s.overall for s in all_scores])
            
            return avg_score, std_dev
        
        return None, None
```

### 方案2: 混合评分（客观指标 + 模型评分）

```python
class HybridScorer:
    """混合评分系统"""
    
    def __init__(self, checker: Checker):
        self.checker = checker
        self.objective_metrics = ObjectiveMetrics()
    
    async def score(self, source, target, draft_a, draft_b, segment_id):
        """混合评分"""
        # 1. 模型评分（主观）
        checker_report = await self.checker.check(
            source, draft_a, draft_b, segment_id
        )
        model_score = checker_report.quality_scores.get(segment_id)
        
        # 2. 客观指标
        length_score = self.objective_metrics.calculate_length_ratio(source, target)
        terminology_score = self.objective_metrics.calculate_terminology_consistency(
            source, target, glossary
        )
        untranslated_score = self.objective_metrics.detect_untranslated_content(target)
        
        # 3. 混合评分（加权平均）
        final_score = QualityScore(
            adequacy=model_score.adequacy * 0.7 + length_score * 0.3,
            fluency=model_score.fluency * 0.8 + untranslated_score * 0.2,
            terminology=model_score.terminology * 0.6 + terminology_score * 0.4,
            overall=(model_score.overall * 0.7 + 
                    (length_score + untranslated_score + terminology_score) / 3 * 0.3)
        )
        
        return final_score
```

## 当前评分流程的优势

### ✅ 已有的客观性保证

1. **双重翻译对比**
   - 两个不同模型的翻译提供对比基础
   - 可以发现一致性和差异

2. **第三方评估**
   - Checker是独立的第三方模型
   - 不参与翻译，只负责评估
   - 减少自我评估的偏见

3. **结构化评分**
   - 明确的评分维度（充分性、流畅性、术语）
   - 0-1的标准化分数
   - 便于对比和分析

4. **低温度参数**
   - Checker使用temperature=0.2
   - 保证评分的稳定性和一致性

5. **具体问题识别**
   - 不仅给分数，还指出具体问题
   - 识别冲突、遗漏、误解
   - 提供改进依据

## 当前评分流程的局限

### ⚠️ 需要改进的地方

1. **单一评分者**
   - 只有一个Checker模型评分
   - 可能存在模型偏见
   - **改进**: 使用多模型评分投票

2. **固定提升值**
   - Aggregator阶段固定提升0.05分
   - 没有实际评估风格化效果
   - **改进**: 实际评估风格化前后的质量变化

3. **缺少客观指标**
   - 完全依赖模型判断
   - 没有可量化的客观指标
   - **改进**: 添加长度比、术语匹配等客观指标

4. **没有基准对比**
   - 没有标准测试集
   - 没有人工评分校准
   - **改进**: 建立标准测试集和人工评分基准
