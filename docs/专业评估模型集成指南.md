## 集成的专业模型

### 1. COMET ⭐⭐⭐⭐⭐（强烈推荐）

**全称**: Crosslingual Optimized Metric for Evaluation of Translation

**特点**:
- 基于XLM-R的跨语言预训练模型
- 同时考虑源文本、译文、参考翻译
- 与人工评估相关性最高（>0.8）
- WMT评测官方使用

**模型选择**:
- `Unbabel/wmt22-comet-da`: 需要参考翻译（推荐）
- `Unbabel/wmt22-cometkiwi-da`: 无需参考翻译（QE模式）
- `Unbabel/XCOMET-XL`: 最新最强（需要更多资源）

**安装**:
```bash
pip install unbabel-comet
```

**使用**:
```python
from src.evaluation.comet_scorer import COMETScorer

scorer = COMETScorer("Unbabel/wmt22-comet-da")
scorer.initialize()

score = scorer.score_single(
    source="Hello, world!",
    translation="你好，世界！",
    reference="你好，世界！"
)
print(f"COMET分数: {score:.4f}")  # 0-1，越高越好
```

**优势**:
- ✅ 相关性最高（与人工评估相关性>0.8）
- ✅ 考虑源文本（不仅是译文-参考对比）
- ✅ 支持多语言
- ✅ WMT官方推荐

### 2. BERTScore ⭐⭐⭐⭐（推荐）

**特点**:
- 基于BERT embedding的语义相似度
- 不依赖表面形式，关注语义
- 轻量级，易于安装

**安装**:
```bash
pip install bert-score
```

**使用**:
```python
from src.evaluation.bertscore_scorer import BERTScoreScorer

scorer = BERTScoreScorer(lang="zh")
scorer.initialize()

f1_score = scorer.score_single(
    translation="你好，世界！",
    reference="你好，世界！"
)
print(f"BERTScore F1: {f1_score:.4f}")
```

**优势**:
- ✅ 安装简单
- ✅ 速度快
- ✅ 语义相似度评估
- ✅ 对同义词不敏感

---

### 3. BLEURT ⭐⭐⭐（可选）

**特点**:
- 基于BERT的评估模型
- 在人工评分数据上微调
- 捕捉细微的语义差异

**安装**（较复杂）:
```bash
pip install git+https://github.com/google-research/bleurt.git
```

**使用**:
```python

scorer = BLEURTScorer("BLEURT-20")
scorer.initialize()

score = scorer.score_single(
    translation="你好，世界！",
    reference="你好，世界！"
)
print(f"BLEURT分数: {score:.4f}")
```

**注意**: 
- ⚠️ 安装较复杂，可能需要特定环境
- ⚠️ 模型较大，首次运行需要下载
- 💡 如果安装困难，可以只用COMET+BERTScore

## 组合评估器

### CombinedQualityScorer

整合所有评估指标，提供综合评分。

**使用方式**:

```python
from src.evaluation.combined_scorer import CombinedQualityScorer

# 初始化
scorer = CombinedQualityScorer(
    use_comet=True,
    use_bleurt=False,  # BLEURT可选
    use_bertscore=True
)
scorer.initialize()

# 评分
result = scorer.score(
    source="Machine learning is...",
    translation="机器学习是...",
    reference="机器学习是...",
    mqm_score={'overall': 0.92}  # 来自Checker的MQM评分
)

# 查看结果
print(f"BLEU: {result.bleu:.4f}")
print(f"COMET: {result.comet:.4f}")
print(f"BERTScore: {result.bertscore_f1:.4f}")
print(f"MQM: {result.mqm_overall:.4f}")
print(f"综合评分: {result.final_score:.4f}")
```

### 综合评分公式

```
综合评分 = COMET × 30% + BERTScore × 20% + BLEURT × 15% + MQM × 25% + BLEU × 10%
```

**权重说明**:
- **COMET 30%**: 最可靠的神经网络评估
- **BERTScore 20%**: 语义相似度
- **MQM 25%**: 多维度人工评估标准
- **BLEURT 15%**: 细粒度语义评估
- **BLEU 10%**: 传统基准指标

## 评估流程

### 完整评估流程

```
1. 翻译文本
   ↓
2. 获取MQM评分（来自Checker）
   ↓
3. 计算BLEU（传统指标）
   ↓
4. 计算COMET（神经网络QE）
   ↓
5. 计算BERTScore（语义相似度）
   ↓
6. 计算BLEURT（可选）
   ↓
7. 综合评分（加权平均）
```

```bash

pip install -r requirements_pro.txt

# 2. 运行评估
python evaluate_with_professional_metrics.py
```

## 论文中的使用

### 评估指标部分

```markdown
## Evaluation Metrics

We employ multiple automatic evaluation metrics:

1. **BLEU** (Papineni et al., 2002): Traditional n-gram matching metric
2. **COMET** (Rei et al., 2020): Neural quality estimation model
3. **BERTScore** (Zhang et al., 2020): Semantic similarity based on BERT
4. **MQM** (Simplified): Multi-dimensional quality metrics
5. **Combined Score**: Weighted average of all metrics

The combined score is calculated as:
Score = 0.3×COMET + 0.2×BERTScore + 0.25×MQM + 0.15×BLEURT + 0.1×BLEU
```

```markdown
Our multi-stage collaborative translation system achieves competitive
```

**解决方案**:

**原因**: 需要下载BERT模型

**解决方案**: 
- 首次运行会自动下载
- 后续运行会使用缓存

### Q3: BLEURT安装失败

**解决方案**: 
- BLEURT可选，不影响核心功能
