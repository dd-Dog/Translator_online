# 组内使用安全配置指南

## 快速决策

**对于组内使用的Web服务，你需要：**

✅ **必须做**:
1. API密钥保护（后端环境变量）
2. IP白名单或简单Token认证
3. 请求速率限制
4. 输入验证
5. CORS配置

❌ **不需要做**:
1. 完整的用户登录系统
2. JWT Token认证
3. 数据库存储用户信息
4. OAuth第三方登录

## 一、API密钥保护（最高优先级）

### 为什么必须？
API密钥泄露会导致账户被盗用，产生高额费用。

### 如何实现？

#### 1. 后端配置（必须）

```python
# backend/app/config.py
import os

class Config:
    # ✅ 正确：从环境变量读取
    OPENROUTER_API_KEY = os.getenv("OPENROUTER_API_KEY")
    QWEN_API_KEY = os.getenv("QWEN_API_KEY")
    
    # ❌ 错误：不要硬编码
    # OPENROUTER_API_KEY = "sk-or-v1-xxx"  # 绝对不要这样做！
```

#### 2. 环境变量文件

创建 `.env` 文件（**不要提交到Git**）:

```bash
# .env
OPENROUTER_API_KEY=sk-or-v1-your-real-key-here
QWEN_API_KEY=your-qwen-key-here
```

#### 3. 检查清单

- [ ] `.env` 文件已加入 `.gitignore`
- [ ] 前端代码中没有任何API密钥
- [ ] 日志中不输出完整密钥（只输出前几位用于调试）
- [ ] 代码中没有硬编码的密钥

## 二、访问控制（防止外部访问）

### 方案A: IP白名单（推荐，最简单）

**适用场景**: 部署在内网或固定IP环境

```python
# backend/app/middleware/ip_whitelist.py
from fastapi import Request, HTTPException
from starlette.middleware.base import BaseHTTPMiddleware
import ipaddress

class IPWhitelistMiddleware(BaseHTTPMiddleware):
    def __init__(self, app, allowed_ips: list):
        super().__init__(app)
        self.allowed_ips = []
        for ip in allowed_ips:
            try:
                # 支持CIDR格式，如 "192.168.1.0/24"
                self.allowed_ips.append(ipaddress.ip_network(ip, strict=False))
            except:
                # 单个IP地址
                self.allowed_ips.append(ipaddress.ip_address(ip))
    
    def is_allowed(self, client_ip: str) -> bool:
        try:
            client = ipaddress.ip_address(client_ip)
            for allowed in self.allowed_ips:
                if isinstance(allowed, ipaddress.IPv4Network):
                    if client in allowed:
                        return True
                else:
                    if client == allowed:
                        return True
            return False
        except:
            return False
    
    async def dispatch(self, request: Request, call_next):
        # 跳过健康检查等公开端点
        if request.url.path in ["/health", "/docs", "/openapi.json"]:
            return await call_next(request)
        
        client_ip = request.client.host
        if not self.is_allowed(client_ip):
            raise HTTPException(
                status_code=403, 
                detail=f"Access denied from {client_ip}"
            )
        return await call_next(request)

# 使用
ALLOWED_IPS = [
    "127.0.0.1",           # 本地
    "192.168.1.0/24",      # 内网段
    "10.0.0.0/8",          # 内网段
]

app.add_middleware(IPWhitelistMiddleware, allowed_ips=ALLOWED_IPS)
```

### 方案B: 简单Token认证（更灵活）

**适用场景**: 需要跨网络访问或IP不固定

```python
# backend/app/middleware/token_auth.py
from fastapi import Request, HTTPException
from starlette.middleware.base import BaseHTTPMiddleware
import os

SHARED_TOKEN = os.getenv("SHARED_TOKEN", "")

class TokenAuthMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        # 跳过健康检查等公开端点
        if request.url.path in ["/health", "/docs", "/openapi.json"]:
            return await call_next(request)
        
        # 检查API端点
        if request.url.path.startswith("/api/"):
            auth_header = request.headers.get("Authorization", "")
            token = auth_header.replace("Bearer ", "").strip()
            
            if not SHARED_TOKEN:
                # 如果没有配置Token，跳过验证（仅开发环境）
                if os.getenv("ENV") == "production":
                    raise HTTPException(
                        status_code=500,
                        detail="Token authentication not configured"
                    )
            elif token != SHARED_TOKEN:
                raise HTTPException(
                    status_code=403,
                    detail="Invalid or missing token"
                )
        
        return await call_next(request)

# 使用
app.add_middleware(TokenAuthMiddleware)
```

**前端配置**:
```javascript
// frontend/src/api/index.js
import axios from 'axios'

const api = axios.create({
  baseURL: 'http://localhost:8000',
  headers: {
    'Authorization': `Bearer ${import.meta.env.VITE_SHARED_TOKEN || ''}`
  }
})
```

**环境变量**:
```bash
# .env (后端)
SHARED_TOKEN=your-group-secret-token-12345

# .env.local (前端，可选)
VITE_SHARED_TOKEN=your-group-secret-token-12345
```

## 三、请求速率限制

### 为什么需要？
防止误操作或恶意请求导致API费用过高。

### 实现方式

```python
# 安装依赖
# pip install slowapi

# backend/app/main.py
from slowapi import Limiter, _rate_limit_exceeded_handler
from slowapi.util import get_remote_address
from slowapi.errors import RateLimitExceeded

limiter = Limiter(key_func=get_remote_address)
app.state.limiter = limiter
app.add_exception_handler(RateLimitExceeded, _rate_limit_exceeded_handler)

@app.post("/api/v1/translate")
@limiter.limit("10/minute")  # 每分钟最多10次
async def translate(request: Request, ...):
    ...

@app.get("/api/v1/history")
@limiter.limit("30/minute")  # 历史记录可以更宽松
async def get_history(request: Request, ...):
    ...
```

**推荐限制**:
- 翻译接口: 10次/分钟
- 历史记录: 30次/分钟
- 术语表: 60次/分钟

## 四、输入验证

### 实现方式

```python
from pydantic import BaseModel, validator, Field

class TranslateRequest(BaseModel):
    text: str = Field(..., min_length=1, max_length=10000)
    source_lang: str = "auto"
    target_lang: str = "zh"
    style: str = "general"
    glossary: dict = {}
    
    @validator('text')
    def validate_text(cls, v):
        if len(v) > 10000:
            raise ValueError('文本长度不能超过10000字符')
        if not v.strip():
            raise ValueError('文本不能为空')
        # 检查是否包含可疑内容（可选）
        if len(v) > 5000 and v.count('\n') < 2:
            # 可能是恶意输入
            pass
        return v.strip()
    
    @validator('style')
    def validate_style(cls, v):
        allowed = ["general", "native", "business", "academic", 
                  "technical", "literary", "news", "colloquial", "legal"]
        if v not in allowed:
            raise ValueError(f'不支持的风格: {v}')
        return v
    
    @validator('glossary')
    def validate_glossary(cls, v):
        if len(v) > 100:
            raise ValueError('术语表不能超过100条')
        # 验证术语格式
        for key, value in v.items():
            if not isinstance(key, str) or not isinstance(value, str):
                raise ValueError('术语表格式错误')
            if len(key) > 50 or len(value) > 100:
                raise ValueError('术语或翻译过长')
        return v
```

## 五、CORS配置

### 实现方式

# 开发环境

    "http://localhost:3000",
    "http://localhost:5173",  # Vite

app.add_middleware(

## 六、完整配置示例

### backend/app/config.py

```python
import os
from typing import List

class SecurityConfig:
    """安全配置"""
    
    # API密钥（必须从环境变量读取）
    OPENROUTER_API_KEY = os.getenv("OPENROUTER_API_KEY")
    QWEN_API_KEY = os.getenv("QWEN_API_KEY")
    
    # 访问控制
    ALLOWED_IPS: List[str] = [
        "127.0.0.1",
        "192.168.1.0/24",  # 内网段，根据实际情况修改
    ]
    
    # 可选：简单Token认证
    SHARED_TOKEN = os.getenv("SHARED_TOKEN", "")
    USE_TOKEN_AUTH = bool(SHARED_TOKEN)
    
    # 请求限制
    RATE_LIMIT_TRANSLATE = "10/minute"
    RATE_LIMIT_HISTORY = "30/minute"
    RATE_LIMIT_GLOSSARY = "60/minute"
    
    # 输入限制
    MAX_TEXT_LENGTH = 10000
    MAX_GLOSSARY_SIZE = 100
    
    # CORS
    ALLOWED_ORIGINS = [
        "http://localhost:3000",
        "http://localhost:5173",
    ]
    
    # 环境
    ENV = os.getenv("ENV", "development")
    
    # 生产环境配置
    if ENV == "production":
        FRONTEND_URL = os.getenv("FRONTEND_URL", "http://localhost:3000")
        if FRONTEND_URL not in ALLOWED_ORIGINS:
            ALLOWED_ORIGINS.append(FRONTEND_URL)
    
    @classmethod
    def validate(cls):
        """验证配置"""
        errors = []
        if not cls.OPENROUTER_API_KEY:
            errors.append("OPENROUTER_API_KEY 未设置")
        if cls.ENV == "production" and not cls.USE_TOKEN_AUTH and not cls.ALLOWED_IPS:
            errors.append("生产环境必须配置访问控制（IP白名单或Token）")
        return errors
```

## 八、常见问题

### Q1: 如果部署在公网怎么办？

**A**: 必须使用Token认证，并且考虑：
- 使用HTTPS（SSL证书）
- 更强的Token（随机生成，定期更换）
- 更严格的速率限制
- 监控和告警

### Q2: IP白名单和Token认证可以同时使用吗？

**A**: 可以，但通常只需要一个。如果IP固定，用IP白名单；如果IP不固定，用Token。

### Q3: 如何生成安全的Token？

**A**: 
```python
import secrets
token = secrets.token_urlsafe(32)  # 生成32字节的随机Token
print(token)  # 保存到环境变量
```

### Q4: 如果忘记Token怎么办？

**A**: 重新生成Token，更新环境变量，重启服务。前端也需要更新。

5. ✅ CORS配置（限制来源）
