# 专业评估模型资源需求评估

## 普通笔记本电脑配置参考

**典型配置**:
- CPU: Intel i5/i7 或 AMD Ryzen 5/7
- 内存: 8-16GB
- 硬盘: 256GB-512GB SSD
- 显卡: 集成显卡（无独立GPU）

---

## 各模型资源需求分析

### 1. BERTScore ✅ 推荐（轻量级）

**资源需求**:
- 内存: ~2-4GB
- 硬盘: ~1GB（模型文件）
- GPU: 不需要（CPU运行良好）
- 首次运行: 需下载BERT模型（~400MB）

**性能**:
- CPU: 1-2秒/句（可接受）
- 批量: 10句约10-20秒

**结论**: ✅ **完全适合普通笔记本**

---

### 2. COMET ⚠️ 可用但较慢

**资源需求**:
- 内存: ~4-8GB
- 硬盘: ~2-3GB（模型文件）
- GPU: 可选（CPU也能运行，但慢）
- 首次运行: 需下载XLM-R模型（~2GB）

**性能**:
- CPU: 5-10秒/句（较慢）
- GPU: 0.5-1秒/句（快）
- 批量10句: 约1-2分钟（CPU）

**模型大小对比**:
- `wmt22-comet-da`: ~2GB（标准）
- `wmt22-cometkiwi-da`: ~1.5GB（轻量）
- `XCOMET-XL`: ~10GB（巨大，不推荐）

**结论**: ⚠️ **可用但慢，建议小批量使用**

---

### 3. BLEURT ❌ 不推荐（资源密集）

**资源需求**:
- 内存: ~8-12GB
- 硬盘: ~5GB（模型文件）
- GPU: 强烈建议（CPU极慢）
- 安装: 复杂，依赖较多

**性能**:
- CPU: 10-30秒/句（很慢）
- GPU: 1-2秒/句

**结论**: ❌ **不推荐普通笔记本使用**

---

## 推荐配置方案

### 方案1: 轻量级配置（推荐）⭐⭐⭐⭐⭐

**使用模型**:
- ✅ BERTScore（必选）
- ✅ BLEU（必选）
- ✅ MQM（自定义，必选）

**资源需求**:
- 内存: 4-6GB
- 时间: 10句约20-30秒
- 安装: 简单

**代码**:
```python
scorer = CombinedQualityScorer(
    use_comet=False,      # 关闭COMET
    use_bleurt=False,     # 关闭BLEURT
    use_bertscore=True    # 只用BERTScore
)
```

**综合评分公式**:
```
Score = BERTScore × 40% + MQM × 40% + BLEU × 20%
```

**适用场景**:
- ✅ 普通笔记本（8GB内存）
- ✅ 快速评估（20秒/10句）
- ✅ 开发调试

---

### 方案2: 标准配置（平衡）⭐⭐⭐⭐

**使用模型**:
- ✅ COMET（可选，小批量）
- ✅ BERTScore（必选）
- ✅ BLEU（必选）
- ✅ MQM（必选）

**资源需求**:
- 内存: 8GB+
- 时间: 10句约2-3分钟
- 安装: 中等

**代码**:
```python
scorer = CombinedQualityScorer(
    use_comet=True,       # 开启COMET（小批量）
    use_bleurt=False,     # 关闭BLEURT
    use_bertscore=True,   # 开启BERTScore
    comet_model="Unbabel/wmt22-cometkiwi-da"  # 使用轻量版
)

# 小批量评估（每次5-10条）
results = []
for batch in batches(test_data, batch_size=5):
    batch_results = await evaluate_batch(batch)
    results.extend(batch_results)
```

**综合评分公式**:
```
Score = COMET × 30% + BERTScore × 25% + MQM × 30% + BLEU × 15%
```

**适用场景**:
- ✅ 笔记本（8-16GB内存）
- ✅ 论文实验（可接受2-3分钟/10句）
- ✅ 最终评估

---

### 方案3: 完整配置（最佳，需GPU）⭐⭐⭐⭐⭐

**使用模型**:
- ✅ COMET（完整版）
- ✅ BLEURT

- ✅ MQM

**资源需求**:
- 内存: 16GB+

## 优化技巧

### 技巧1: 批量处理

```python
# 不推荐：逐条评估
for item in test_data:
    score = scorer.score(item['source'], item['translation'])

# 推荐：批量评估（更高效）
sources = [item['source'] for item in test_data]
translations = [item['translation'] for item in test_data]
scores = scorer.batch_score(sources, translations)
```

### 技巧2: 缓存结果

```python
# 评估结果缓存，避免重复计算
import pickle

# 保存
with open('evaluation_cache.pkl', 'wb') as f:
    pickle.dump(results, f)

# 加载
with open('evaluation_cache.pkl', 'rb') as f:
    results = pickle.load(f)
```
