# 评估器环境配置指南

## 概述

如果 `translation_evaluator` 安装在单独的 conda 环境中，可以通过配置文件指定使用该环境。

## 配置方法

### 1. 编辑配置文件

打开 `config/evaluation.yaml`，找到 `evaluator_env` 部分：

```yaml
evaluator_env:
  # 方式1: 指定 conda 环境名称（推荐）
  conda_env_name: "evaluator_env"  # 取消注释并填入你的环境名称
  
  # 方式2: 直接指定 Python 可执行文件路径（如果方式1不工作）
  # python_path: "C:/Users/YourName/miniconda3/envs/evaluator_env/python.exe"
  
  # 方式3: 使用当前环境的 Python（默认，如果 translation_evaluator 已安装到当前环境）
  use_current_env: true
```

### 2. 配置选项说明

#### 方式1: 使用 conda 环境名称（推荐）

```yaml
evaluator_env:
  conda_env_name: "evaluator_env"  # 你的 conda 环境名称
  use_current_env: false
```

**优点**：
- 简单易用
- 自动查找环境路径
- 跨平台兼容

**要求**：
- 系统已安装 conda
- conda 命令在 PATH 中可用

#### 方式2: 直接指定 Python 路径

```yaml
evaluator_env:
  python_path: "C:/Users/YourName/miniconda3/envs/evaluator_env/python.exe"
  use_current_env: false
```

**优点**：
- 不依赖 conda 命令
- 精确控制 Python 路径

**适用场景**：
- conda 命令不可用
- 使用自定义 Python 安装
- 需要精确指定路径

#### 方式3: 使用当前环境（默认）

```yaml
evaluator_env:
  use_current_env: true
```

**适用场景**：
- `translation_evaluator` 已安装到当前 conda 环境
- 不需要环境隔离

## 配置示例

### 示例1: 使用单独的 conda 环境

假设你创建了一个名为 `evaluator` 的 conda 环境，并在其中安装了 `translation_evaluator`：

```yaml
evaluator_env:
  conda_env_name: "evaluator"
  use_current_env: false
```

### 示例2: Windows 系统，指定完整路径

```yaml
evaluator_env:
  python_path: "C:/Users/YourName/miniconda3/envs/evaluator/python.exe"
  use_current_env: false
```

### 示例3: Linux/Mac 系统

```yaml
evaluator_env:
  conda_env_name: "evaluator"
  use_current_env: false
```

或者：

```yaml
evaluator_env:
  python_path: "/home/username/miniconda3/envs/evaluator/bin/python"
  use_current_env: false
```

## 环境查找逻辑

系统会按以下顺序查找 conda 环境：

1. **使用 conda info 命令**：查询 conda 环境列表
2. **常见安装路径**：
   - `~/miniconda3/envs/{env_name}`
   - `~/anaconda3/envs/{env_name}`
   - `C:/Users/{username}/miniconda3/envs/{env_name}`
   - `C:/Users/{username}/anaconda3/envs/{env_name}`
3. **使用 conda run 命令**：如果可用

## 验证配置

运行测试脚本，查看输出：

```bash
python test_full_evaluation_v2.py
```

如果配置成功，你会看到：

```
[OK] 使用评估器 conda 环境: C:\Users\YourName\miniconda3\envs\evaluator\python.exe
[OK] 已添加评估器环境 site-packages: ...
[OK] 评估库导入成功
```

如果配置失败，会显示警告信息，帮助你排查问题。

## 常见问题

### Q1: 找不到 conda 环境

**问题**：配置了 `conda_env_name`，但提示找不到环境

**解决方案**：
1. 确认环境名称正确：`conda env list`
2. 使用方式2，直接指定 Python 路径
3. 检查 conda 命令是否在 PATH 中：`conda --version`

### Q2: 导入失败

**问题**：环境路径找到了，但导入 `translation_evaluator` 失败

**解决方案**：
1. 确认在指定环境中已安装 `translation_evaluator`：
   ```bash
   conda activate evaluator_env
   python -c "import translation_evaluator; print('OK')"
   ```
2. 如果未安装，在指定环境中安装：
   ```bash
   conda activate evaluator_env
   cd C:\workspace\python\translation_evaluator
   pip install -e .
   ```

### Q3: 路径格式问题（Windows）

**问题**：Windows 路径格式错误

**解决方案**：
- 使用正斜杠 `/` 或双反斜杠 `\\`
- 示例：`C:/Users/Name/miniconda3/envs/evaluator/python.exe`
- 或：`C:\\Users\\Name\\miniconda3\\envs\\evaluator\\python.exe`

### Q4: 权限问题

**问题**：无法访问 conda 环境路径

**解决方案**：
- 检查文件权限
- 确认路径存在且可读
- 在管理员模式下运行（如果需要）

## 最佳实践

1. **推荐使用方式1（conda_env_name）**：最简单，跨平台兼容
2. **环境命名规范**：使用清晰的环境名称，如 `evaluator`、`translation_eval`
3. **路径配置**：如果方式1不工作，再使用方式2
4. **测试验证**：配置后运行测试脚本验证是否正常工作

## 技术细节

### 工作原理

1. 读取 `config/evaluation.yaml` 中的 `evaluator_env` 配置
2. 根据配置查找 conda 环境的 Python 路径
3. 将环境的 `site-packages` 目录添加到 `sys.path`
4. 导入 `translation_evaluator` 模块

### 代码位置

- 配置工具：`src/utils/evaluator_env.py`
- 配置文件：`config/evaluation.yaml`
- 使用示例：`test_full_evaluation_v2.py`

## 相关文件

- `config/evaluation.yaml` - 评估器配置文件
- `src/utils/evaluator_env.py` - 环境配置工具
